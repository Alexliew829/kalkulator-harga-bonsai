Kalkulator Harga Bonsai V7.0

V7.0 以 V6.9 为唯一基准，只新增本次确认的“原成本精确搜索”功能；V6.9 已稳定的售价、运费、汇率与产品逻辑保持不变：
- 手动门市模式：门市 <= RM500 时直播=门市；门市 > RM500 时，直播=门市 x 92%，向下取 RM50，并以 RM500 为直播保底，避免 RM500/RM501 倒挂。
- 手动门市模式最低售价继续使用：直播 x 80%，取最接近 RM10。
- TikTok 继续保持：门市 x 82%，取最接近 RM10；没有改动。
- 产品编号模式：Import 返回的最低售价继续作为绝对底线，不重新计算、不降低。
- 产品编号模式不再自动生成/显示反推门市价，避免与实体树原有门市标签冲突。
- 产品编号模式直播价保留 V6.8 已验证的反推逻辑，避免既有产品售价整体漂移；例如 Import 最低 RM900 的产品继续得到直播 RM1,200。
- 产品搜索、产品名/编号、快速缓存、运费、汇率、Postcode、台湾/印尼逻辑、UI 排版及其他已经稳定的计算逻辑全部保持 V6.8 不变。

验收例：
- 手动门市 RM480 -> 直播 RM480 -> 最低 RM380。
- 手动门市 RM500 -> 直播 RM500 -> 最低 RM400。
- 手动门市 RM501 -> 直播 RM500 -> 最低 RM400。
- 手动门市 RM580 -> 直播 RM500 -> 最低 RM400。
- 手动门市 RM598 -> 直播 RM550 -> 最低 RM440。
- 手动门市 RM1,680 -> 直播 RM1,500 -> 最低 RM1,200。
- 产品 BX0035（Import 最低 RM900）-> 门市不生成/不显示 -> 直播 RM1,200 -> 最低 RM900。

Apps Script / Code.gs：不需要更新。
Import System：不需要修改或重新部署。


V7.0 新增：
- 所有产品输入框支持 Import V21.8 同款“原成本精确搜索”。
- 纯数字查询只匹配原成本，不再匹配产品名称/编号中的数字。
- 输入 120 只匹配原成本 120 / 120.00；不会匹配 1200、1201。
- 不区分原成本币种。
- 非数字查询继续使用 V6.9 原本编号/名称/兼容编号搜索逻辑。
- 原成本查询通过只读安全搜索桥接，仅返回产品编号、名称、有效最低售价；不把原成本值下载到主播端。
